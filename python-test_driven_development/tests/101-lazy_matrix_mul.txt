The ``101-lazy_matrix_mul`` module
==================================

Using ``lazy_matrix_mul``
-------------------------

Import the function:

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Two square matrices are multiplied:

    >>> lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]])
    array([[ 7, 10],
           [15, 22]])

Matrices of different shapes are multiplied when their sizes agree:

    >>> lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]])
    array([[13, 16]])

    >>> lazy_matrix_mul([[2]], [[3]])
    array([[6]])

Floats and negative numbers are accepted:

    >>> lazy_matrix_mul([[1.5, 2.0]], [[2.0], [0.5]])
    array([[4.]])

    >>> lazy_matrix_mul([[-1, 2]], [[3], [-4]])
    array([[-11]])

The exceptions come from NumPy, so only their type is checked here,
their messages change from one version of NumPy to another.

Matrices whose sizes do not agree cannot be multiplied:

    >>> try:
    ...     lazy_matrix_mul([[1, 2]], [[3, 4]])
    ... except ValueError:
    ...     print("ValueError")
    ValueError

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2, 3]])
    ... except ValueError:
    ...     print("ValueError")
    ValueError

An empty matrix cannot be multiplied:

    >>> try:
    ...     lazy_matrix_mul([[]], [[]])
    ... except ValueError:
    ...     print("ValueError")
    ValueError

An element that is not a number is a type error:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, "4"]], [[1, 2], [3, 4]])
    ... except TypeError:
    ...     print("TypeError")
    TypeError

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, None]])
    ... except TypeError:
    ...     print("TypeError")
    TypeError

An argument that is not a matrix of numbers is refused:

    >>> try:
    ...     lazy_matrix_mul("m_a", [[1, 2], [3, 4]])
    ... except (TypeError, ValueError):
    ...     print("error")
    error

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], None)
    ... except (TypeError, ValueError):
    ...     print("error")
    error

A matrix that is not a rectangle is refused:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4, 5]], [[1, 2], [3, 4]])
    ... except (TypeError, ValueError):
    ...     print("error")
    error

Both arguments are required:

    >>> lazy_matrix_mul([[1, 2], [3, 4]])
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 1 required positional argument: 'm_b'

    >>> lazy_matrix_mul()
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 2 required positional arguments: 'm_a' and 'm_b'
