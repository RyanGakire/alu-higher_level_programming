The ``101-lazy_matrix_mul`` module
==================================

Using ``lazy_matrix_mul``
-------------------------

Import the function:

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Two square matrices are multiplied:

    >>> lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]])
    array([[ 7, 10],
           [15, 22]])

Matrices of different shapes are multiplied when their sizes agree:

    >>> lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]])
    array([[13, 16]])

    >>> lazy_matrix_mul([[2]], [[3]])
    array([[6]])

Floats and negative numbers are accepted:

    >>> lazy_matrix_mul([[1.5, 2.0]], [[2.0], [0.5]])
    array([[4.]])

    >>> lazy_matrix_mul([[-1, 2]], [[3], [-4]])
    array([[-11]])

The exceptions are raised by NumPy, and their messages change from one
version of NumPy to another, so only their type is checked below.

``m_a`` is a string, ``m_b`` is a list of lists of numbers:

    >>> try:
    ...     lazy_matrix_mul("m_a", [[1, 2], [3, 4]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

``m_a`` is a list of lists of numbers, ``m_b`` is a string:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], "m_b")
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

``m_a`` is empty, ``m_b`` is a list of lists of numbers:

    >>> try:
    ...     lazy_matrix_mul([], [[1, 2], [3, 4]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

    >>> try:
    ...     lazy_matrix_mul([[]], [[1, 2], [3, 4]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

``m_a`` is a list of lists of numbers, ``m_b`` is empty:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [[]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

``m_a`` holds something else than numbers:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, "4"]], [[1, 2], [3, 4]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

``m_b`` holds something else than numbers:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, None]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

The rows of ``m_a`` are not all of the same size:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4, 5]], [[1, 2], [3, 4]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

The rows of ``m_b`` are not all of the same size:

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4, 5]])
    ... except (TypeError, ValueError):
    ...     print("error raised")
    error raised

``m_a`` and ``m_b`` cannot be multiplied:

    >>> try:
    ...     lazy_matrix_mul([[1, 2]], [[3, 4]])
    ... except ValueError:
    ...     print("ValueError raised")
    ValueError raised

    >>> try:
    ...     lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2, 3]])
    ... except ValueError:
    ...     print("ValueError raised")
    ValueError raised

Both arguments are required:

    >>> lazy_matrix_mul([[1, 2], [3, 4]])
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 1 required positional argument: 'm_b'

    >>> lazy_matrix_mul()
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 2 required positional arguments: 'm_a' and 'm_b'
