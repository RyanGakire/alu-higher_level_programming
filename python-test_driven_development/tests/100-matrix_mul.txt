Using ``matrix_mul``
--------------------

Import the function:

    >>> matrix_mul = __import__('100-matrix_mul').matrix_mul

Two square matrices are multiplied:

    >>> matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]])
    [[7, 10], [15, 22]]

Matrices of different shapes are multiplied when their sizes agree:

    >>> matrix_mul([[1, 2]], [[3, 4], [5, 6]])
    [[13, 16]]

    >>> matrix_mul([[1, 2], [3, 4], [5, 6]], [[1, 2, 3], [4, 5, 6]])
    [[9, 12, 15], [19, 26, 33], [29, 40, 51]]

A single element matrix works:

    >>> matrix_mul([[2]], [[3]])

Floats and negative numbers are accepted:

    >>> matrix_mul([[1.5, 2.0]], [[2.0], [0.5]])
    [[4.0]]

    >>> matrix_mul([[-1, 2]], [[3], [-4]])
