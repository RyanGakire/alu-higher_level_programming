The ``3-say_my_name`` module
============================

Using ``say_my_name``
---------------------

Import the function:

    >>> say_my_name = __import__('3-say_my_name').say_my_name

A first name and a last name are printed together:

    >>> say_my_name("John", "Smith")
    My name is John Smith

    >>> say_my_name("Walter", "White")
    My name is Walter White

``last_name`` defaults to an empty string, leaving a trailing space:

    >>> say_my_name("Bob")
    My name is Bob 

Empty strings are valid names:

    >>> say_my_name("", "")
    My name is
