The ``0-add_integer`` module
============================

Using ``add_integer``
---------------------

Import the function:

    >>> add_integer = __import__('0-add_integer').add_integer

Two integers are added normally:

    >>> add_integer(1, 2)
    3

    >>> add_integer(100, -2)
    98

    >>> add_integer(-3, -4)
    -7

``b`` defaults to 98 when it is not given:

    >>> add_integer(2)
    100

Floats are casted to integers, so they are truncated toward zero:

    >>> add_integer(100.3, -2)
    98

    >>> add_integer(-1.5, -1.5)
    -2

    >>> add_integer(2.9)
    100

Booleans are integers in Python, so they are accepted:

    >>> add_integer(True, 2)
    3
