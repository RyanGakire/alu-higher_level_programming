The ``2-matrix_divided`` module
===============================

Using ``matrix_divided``
------------------------

Import the function:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

A matrix of integers is divided element by element:

    >>> matrix_divided([[1, 2, 3], [4, 5, 6]], 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The matrix given as argument is not modified:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Floats are accepted, both in the matrix and as divisor:

    >>> matrix_divided([[1.5, 2.5], [3.5, 4.5]], 2)
    [[0.75, 1.25], [1.75, 2.25]]

    >>> matrix_divided([[1, 2], [3, 4]], 2.5)
    [[0.4, 0.8], [1.2, 1.6]]

A negative divisor works as well:

    >>> matrix_divided([[1, 2], [3, 4]], -2)
    [[-0.5, -1.0], [-1.5, -2.0]]

A single row matrix is valid:

    >>> matrix_divided([[10, 20]], 5)
    [[2.0, 4.0]]

Dividing by zero raises a ZeroDivisionError:
