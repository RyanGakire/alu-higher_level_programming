Using ``print_square``
----------------------

Import the function:

    >>> print_square = __import__('4-print_square').print_square

A square is printed with the ``#`` character:

    >>> print_square(4)

    ####
    ####
    ####

    >>> print_square(2)

    >>> print_square(1)

    >>> print_square(0)
